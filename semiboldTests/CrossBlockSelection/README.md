이 폴더는 크로스 블록 선택(여러 블록에 걸친 연속 드래그 선택) 및
복사/붙여넣기 기능의 선택·복사·붙여넣기 동작을 다루는 테스트를
한곳에 모아두기 위한 디렉토리입니다 —
중복이 생기더라도 이 폴더 하나만 보면 이 기능 전체의 정합성을 파악할
수 있게 하는 것이 목적입니다.

**아직 구현 전입니다.** 지금은 실행 가능한 테스트 코드가 없고, 이
문서가 먼저 정책을 정리해 둔 것입니다. 착수되면 이 문서를 기준으로
테스트를 작성합니다.

아래 정책 문서가 실제 코드보다 먼저입니다 — 코드 동작이 아래 내용과
다르다면, 그건 버그이거나 문서가 낡은 것입니다. 이 문서는 특정 플랫폼
구현에 종속되지 않는 독립 문서입니다 — iOS뿐 아니라 이 기능을
구현하는 모든 플랫폼이 함께 참조합니다.

## 공통 용어

- **문서 좌표**: 문서 안의 한 지점을 가리키는 좌표입니다 — 어느
  블록의 몇 번째 문자 위치인지, "블록 + 그 블록 안에서의 문자
  오프셋" 쌍으로 나타냅니다.
- **선택 범위**: 두 문서 좌표(시작/끝)로 표현되는 구간입니다. 드래그
  방향과 무관하게, 문서상 배열 순서로 앞에 있는 쪽이 항상
  "시작"입니다(뒤에서 앞으로 드래그해도 뒤집지 않고 정규화합니다).
- **경계 블록**: 선택 범위의 시작 또는 끝이 그 블록 텍스트의 중간에
  걸쳐 있는 블록입니다 — 블록 전체가 아니라 일부 문자 구간만
  선택됩니다.
- **전체 선택 블록**: 선택 범위에 완전히 포함되어, 블록 전체(텍스트
  전부 + 종류/스타일)가 선택 대상인 블록입니다. 경계 블록이 아닌,
  선택 범위 중간에 낀 모든 블록이 여기 해당합니다.
- **편집 모드**: 특정 블록에 키보드 포커스가 가 있어 타이핑 중인
  상태입니다. 선택 모드와 동시에 성립하지 않습니다 — 크로스 블록
  선택이 시작되면 편집 모드는 해제됩니다.

## 공통 불변조건

아래 조건은 선택·복사·붙여넣기 동작이 끝난 뒤 항상 만족해야 합니다.

1. 선택 범위는 항상 문서상 배열 순서로 시작 ≤ 끝입니다 — 드래그
   방향과 무관합니다.
2. 편집 모드와 선택 모드는 동시에 성립하지 않습니다.
3. 복사 결과물에서, 전체 선택 블록은 원본과 동일한 종류/스타일/텍스트
   전부를 그대로 담습니다.
4. 복사 결과물에서, 경계 블록은 선택된 문자 구간의 텍스트만 담되,
   원본 블록의 종류/스타일(헤딩 레벨, 리스트 종류 등)은 그대로
   유지합니다.
5. 같은 문서/다른 문서에 붙여넣을 때 모든 블록은 새 id를 받습니다 —
   원본 id를 재사용하지 않습니다.
6. 선택 범위에 포함된 리스트 블록 중 원본에서 같은 `listGroupId`를
   공유하던 항목들은, 붙여넣은 뒤에도 하나의 새 그룹을 함께
   가리킵니다 — 서로 다른 그룹으로 쪼개지지 않습니다.
7. 붙여넣은 조각의 첫 블록이 조상 없이 depth > 0으로 시작하면, 첫
   블록을 depth 0으로 클램프하고 나머지 블록은 원래의 상대적 깊이
   차이를 그대로 유지합니다 — 배열상 인접한 두 블록의 depth 차이는
   항상 최대 1이어야 한다는 리스트 블록의 기본 규칙을, 붙여넣기
   후에도 깨지 않기 위함입니다.
8. 이 앱 밖에 붙여넣을 때는 Markdown 텍스트로 변환된 결과가 쓰입니다
   — 표현 못 하는 블록 종류는 근사치로 변환되거나 생략될 수 있고,
   완벽한 재현을 보장하지 않습니다.

## 시나리오 카탈로그

### A. 선택 시작/확장 (제스처)

**A1. 블록 하나의 텍스트 중간에서 롱프레스** — 선택 범위 없이 그
지점에 빈 커서만 놓입니다 — 단어 단위로 바로 선택되지 않습니다.
단어 단위로 선택하려면, 이때 뜨는 텍스트 선택 메뉴의
"선택"(Select) 버튼을 눌러야 합니다(결정됨, 2026-08-21).

**A2. 같은 블록 안에서 드래그 확장** — 이 구간은 iOS 네이티브
텍스트 선택 동작을 그대로 사용합니다(경계를 넘지 않았으므로 커스텀
로직이 개입하지 않습니다).

**A3. 드래그가 현재 블록의 위/아래 경계를 넘음** — 이 시점부터
커스텀 크로스 블록 선택 로직이 개입합니다. 네이티브 선택 핸들/캐럿
표시는 멈추고, 선택 범위가 여러 블록에 걸친 상태로 갱신됩니다.

**A4. 시작점보다 위(문서상 앞)로 드래그** — 선택 범위는 불변조건
1에 따라 정규화됩니다 — "시작"과 "끝"이 드래그 순서가 아니라 문서
순서 기준으로 재배정됩니다.

**A5. 드래그 중 화면이 스크롤되는 경우** — 드래그 지점이 화면 위/아래
가장자리 뷰포트에 닿으면 자동으로 스크롤되고, 스크롤되는 동안에도
선택 범위가 계속 연장됩니다(결정됨, 2026-08-21).

**A6. 선택 도중 다른 화면 요소를 탭함**
a. 다른 블록을 탭하면: 그 블록의 탭한 위치로 포커스가 옮겨가며
편집 모드로 전환되고, 기존 선택 범위는 해제됩니다.
b. 키보드 툴바의 "키보드 내리기" 버튼을 탭하면: 선택은 취소되지
않습니다 — 선택 상태를 유지한 채 키보드만 내려갑니다.
c. 그 외(내비게이션 바 등) 화면 요소를 탭하면: 선택이 취소되고
선택 범위가 사라집니다.
(a/b는 결정됨, 2026-08-21 — 다만 구현 난이도에 따라 재검토될 수
있습니다.)

### B. 복사

**B1. 선택 범위를 복사** — 불변조건 3/4에 따라 전체 선택 블록과
경계 블록을 구분해 직렬화하고, 앱 자체 포맷(JSON, 무손실)과 Markdown
폴백(손실 허용)을 한 클립보드 항목에 함께 담습니다.

**B2. 선택 범위 안에 리스트 블록의 일부만 포함된 경우** (예: 같은
그룹의 항목 3개 중 가운데 1개만 선택 범위 안) — 선택 자체는
`listGroupId` 재배정이나 그룹 관계 처리를 하지 않습니다(선택은 순수
좌표 상태일 뿐, 아무것도 변형하지 않습니다). 이 관계 처리는
복사·삭제·붙여넣기 같은 후처리 단계의 문제로, 실제 복사/붙여넣기
절차(B1/C1 등)를 구현할 때 다시 논의합니다(2026-08-21).

### C. 붙여넣기

**C1. 같은 문서에 붙여넣기** — 앱 자체 포맷(JSON)을 그대로 디코드,
불변조건 5/6/7을 적용합니다.

**C2. 다른 문서에 붙여넣기** — C1과 동일하되 `documentId`를 붙여넣기
대상 문서로 재작성합니다.

**C3. 선택 범위의 첫 블록이 조상 없이 depth > 0으로 시작하는 조각을
붙여넣기** — 불변조건 7에 따라 depth를 보정합니다.

**C4. 이 앱 밖에서 복사한 일반 텍스트를 이 앱에 붙여넣기** — 이번
스코프에 포함합니다(결정됨, 2026-08-21). 줄바꿈 기준으로 최소한
문단 블록을 나눠 받고, 각 줄이 마크다운 문법(`"- "`/`"# "`/`"1. "`
등)을 포함하면 그 줄은 해당 종류의 블록으로 파싱해서 변환합니다.
완전한 Markdown 문서 임포터가 아니라, 이미 있는 프리픽스 변환
규칙(A2)을 붙여넣는 텍스트의 각 줄에 적용하는 수준입니다.

**C5. 이 앱 밖(메모, 메시지 등)에 붙여넣기** — 불변조건 8에 따라
Markdown 텍스트가 쓰입니다.

## 테스트 작성 방식

코드를 몰라도 각 테스트가 무엇을 검증하는지 읽을 수 있도록, 아래 네
부분이 드러나게 작성합니다.

- **초기 상태**: 문서의 블록 순서/종류/depth/그룹, 선택 범위(있다면).
- **사용자 행동**: 위 A~C 항목 중 어떤 시나리오인지 밝힙니다.
- **기대 결과**: 선택 범위/복사 결과/붙여넣은 블록들이 어떻게
  되는지 설명합니다.
- **확인할 불변조건**: 결과가 위 "공통 불변조건" 중 무엇을 지키는지
  확인합니다.

예시:

```text
초기 상태
- paragraph A: "Hello world"
- bulleted B: depth 0, group G1, "item one"
- bulleted C: depth 1, group G1, "item two"

사용자 행동
- A의 "world" 중간부터 C의 "item" 중간까지 드래그 선택 후 복사,
  다른 문서에 붙여넣기 (A3 → B1 → C2)

기대 결과
- A는 경계 블록으로 "world" 이후 텍스트만 paragraph로 복사된다
- B는 전체 선택 블록으로 그대로 복사된다 (depth 0)
- C는 경계 블록으로 "item"까지만 복사되지만 depth 1은 유지된다
- B와 C는 붙여넣은 문서에서 새로 만든 하나의 ListGroup을 함께 가리킨다

확인할 불변조건
- 경계 블록은 부분 텍스트 + 원래 종류 유지 (불변조건 4)
- 같은 원본 그룹은 붙여넣기 후에도 하나의 그룹 (불변조건 6)
- 모든 붙여넣은 블록은 새 id (불변조건 5)
```
